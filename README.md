# Приказы по Оренбургскому казачьему войску — поисковый указатель

Статический просмотрщик разобранных приказов по Оренбургскому казачьему войску
(пока разобран 1906 год). Позволяет искать:

- персоны — по фамилии, имени, отчеству, месту, отделу, виду приказа и году рождения;
- фамилии — сколько упоминаний, как написано в источнике, где встречается;
- населённые пункты — станицы, посёлки, выселки и города со всеми упоминаниями;
- тексты приказов — полнотекстовый поиск в старой орфографии;
- страницы приказов рядом со сканом, с подсветкой нужной строки.

Данные собраны автоматически из сканов приказов и содержат ошибки распознавания —
перед использованием сверяйте с исходным сканом. Сканы страниц подгружаются с
Яндекс Диска.
