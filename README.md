# Указатели по генеалогии и локальной истории

Статический сайт с двумя поисковыми базами по документам о казаках Оренбургского
казачьего войска.

## Приказы по Оренбургскому казачьему войску

Указатель к печатным приказам (пока разобран 1906 год). Позволяет искать:

- персоны — по фамилии, имени, отчеству, месту, отделу, виду приказа и году рождения;
- фамилии — сколько упоминаний, как написано в источнике, где встречается;
- населённые пункты — станицы, посёлки, выселки и города со всеми упоминаниями;
- тексты приказов — полнотекстовый поиск в старой орфографии;
- страницы приказов рядом со сканом, с подсветкой нужной строки.

## Жители Еткульской и Еманжелинской станиц и их посёлков

База людей по документам о жителях станиц. Первый документ — ревизская сказка по казакам
1834 года, Оренбургской губернии Челябинского уезда 1 Казачьего Кантона Еткульской Станицы
(НАРБ И-138-2-499). Фамилии корректировались на основании труда Василия Вишневского
«Справочник фамилий Оренбургского казачьего войска, а также причисленных к нему территорий
и сословий: 1816–1850 гг.». Для каждой записи — семья целиком, возрасты по ревизиям 1816
и 1834 годов, расчётный год рождения, выбытие и скан документа.

## Данные

Данные собраны автоматически из сканов и содержат ошибки распознавания — перед
использованием сверяйте с исходным сканом. Сканы подгружаются с Яндекс Диска.
